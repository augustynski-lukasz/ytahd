# YouTube as a Hard Drive (YTAHD)

High-performance CLI tool (C# / .NET 8) to encode arbitrary binary data into 4K@60fps video frames
designed to survive YouTube's lossy compression (VP9/AV1). Includes Phase 1 monochrome 16x16
macroblock modulation, SkiaSharp-based renderer, and FFmpeg piping. Test project with xUnit included.

See README.md for design and roadmap.
